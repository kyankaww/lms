Pertanyaan yang Sering Diajukan

Bagaimana cara menerima pendaftar menjadi siswa?

Buka menu Pendaftaran, klik detail pada baris pendaftar, ubah status menjadi Diterima, lalu simpan. Sistem otomatis membuat data siswa dan tagihan pembayaran.

Mengapa data kembali ke contoh awal?

Data demo akan direset ketika versi data awal (seed) diperbarui. Ini menjaga agar contoh data selalu sesuai dengan fitur terbaru.

Apakah file dokumen benar-benar tersimpan?

Belum. Prototype ini hanya menyimpan nama file pada penyimpanan lokal browser. Penyimpanan file sebenarnya memerlukan backend atau layanan object storage.

Bagaimana menonaktifkan akun peserta?

Buka menu Pengguna, klik Nonaktifkan. Peserta dengan status tidak aktif tidak dapat masuk kembali ke portal. Akun admin utama dilindungi.

Apakah data ini aman untuk produksi?

Tidak. Autentikasi, password, dan data masih disimulasikan di frontend. Untuk produksi diperlukan backend, validasi server, serta penyimpanan data yang aman.
